  - O(1) lookup performance

================================================================================
LANGGRAPH STATE MACHINE
================================================================================

STATE (TypedDict):
  - message: str (user input)
  - user_id: int (Telegram ID)
  - intent: str (classified intent)
  - intent_confidence: float (0.0-1.0)
  - selected_agent: Optional[str] (agent name)
  - plan: list[str] (action steps)
  - approval_status: str (pending_approval, approved, rejected, completed)
  - result: str (final response)
  - memory_context: str (user context)
  - conversation_history: list[dict] (message history)
  - error: Optional[str] (error message)

NODES:
  1. classify_intent → Use Haiku for intent classification
  2. route_to_agent → Select appropriate agent
  3. generate_plan → Use Sonnet to create plan
  4. await_approval → Wait for user response (callback-driven)
  5. execute_plan → Execute approved plan
  6. format_response → Prepare response for user

ROUTING:
  classify_intent
    ↓
  route_to_agent
    ↓
  generate_plan
    ├─ if error → format_response
    ├─ if needs_clarification → format_response
    ├─ if multi-step → await_approval
    └─ if single-step → execute_plan
        ↓
      execute_plan
        ↓
      format_response
        ↓
      END

ENVIRONMENT VARIABLES
================================================================================

REQUIRED:
  TELEGRAM_BOT_TOKEN          - Bot token from @BotFather
  TELEGRAM_USER_WHITELIST     - Comma-separated user IDs (e.g., "123,456,789")
  ANTHROPIC_API_KEY           - Anthropic API key

OPTIONAL (with defaults):
  REDIS_URL                   - Default: redis://localhost:6379
  REDIS_DB                    - Default: 0
  RATE_LIMIT_PER_MINUTE       - Default: 10
  MAX_INPUT_LENGTH            - Default: 2000
  LOG_LEVEL                   - Default: INFO
  USE_WEBHOOK                 - Default: false
  WEBHOOK_DOMAIN              - Required if USE_WEBHOOK=true
  WEBHOOK_URL                 - Required if USE_WEBHOOK=true
  WEBHOOK_PORT                - Default: 8443

DEPLOYMENT MODES
================================================================================

DEVELOPMENT (Polling):
  $ python -m bot.main
  - Continuously polls Telegram for updates
  - No HTTPS required
  - Slower but simple

PRODUCTION (Webhook):
  $ docker-compose up -d
  OR
  $ systemctl start personal-agent
  - Receives updates via HTTPS
  - Requires SSL certificate
  - Low latency
  - Scales better

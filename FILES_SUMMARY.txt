QUICK START
================================================================================

1. Copy .env.example to .env
2. Edit .env with your values (bot token, API keys, webhook URL, etc.)
3. docker-compose build
4. docker-compose up -d
5. python validate_config.py  (optional but recommended)
6. docker-compose ps  (verify all services healthy)

That's it! Services are now running.

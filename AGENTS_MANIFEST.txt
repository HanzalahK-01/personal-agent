DATA FLOW:
==========

User Request
    ↓
Agent.plan(message, context, memory)
    ↓
Claude generates step-by-step plan (PlanStep objects)
    ↓
Agent.execute(plan, context, mcp_client)
    ↓
Execute each step with retry logic, collect results
    ↓
ExecutionResult (success status, completed steps, failed steps)
    ↓
Agent.reflect(result)
    ↓
Summary for user

ERROR HANDLING:
===============

Each step has:
- Max 2 automatic retries
- Exponential backoff (2^retry_count seconds)
- Detailed error logging
- Partial success handling
- User-friendly error messages

DEPLOYMENT NOTES:
=================

1. Install dependencies:
   pip install anthropic structlog

2. Set up environment:
   export ANTHROPIC_API_KEY=your_key

3. Import agents:
   from agents import SchedulerAgent, get_agent_for_intent
   agent = SchedulerAgent()

4. Use async pattern:
   import asyncio
   result = await agent.plan(message, context)

5. Configure Claude model:
   Uses: claude-3-5-sonnet-20241022
   Max tokens: 2000 (planning), 500 (reflection)

QUICK REFERENCE
================================================================================

SETUP (5 minutes):
  1. cp .env.example .env
  2. nano .env  (fill in values)
  3. docker-compose build
  4. docker-compose up -d
  5. docker-compose ps  (verify health)

CONFIGURATION:
  from config import settings
  
  settings.telegram.bot_token
  settings.database.dsn
  settings.security.rate_limit_per_minute
  settings.anthropic.api_key

COMMON COMMANDS:
  docker-compose logs -f bot
  docker-compose exec postgres psql -U agent_user
  docker-compose restart bot
  docker-compose down

SECURITY CHECKLIST:
  [ ] Change POSTGRES_PASSWORD
  [ ] Set ENVIRONMENT=production
  [ ] Configure TELEGRAM_WEBHOOK_URL
  [ ] Set TELEGRAM_ALLOWED_USER_IDS
  [ ] Run validate_config.py
  [ ] Set firewall to allow only 8443
  [ ] Configure HTTPS

BEFORE DEPLOYMENT
================================================================================

1. Review INFRASTRUCTURE.md (architecture and setup)
2. Copy .env.example to .env
3. Configure all variables (especially secrets)
4. Run validate_config.py (catch errors early)
5. Test locally or staging first
6. Set up HTTPS for webhook
7. Configure firewall (allow only 8443)
8. Set up monitoring
9. Configure backups for PostgreSQL
10. Document any custom settings

ARCHITECTURE AT A GLANCE
================================================================================

User → HTTPS Webhook → Bot Service (port 8443)
                          ↓
                    ┌─────┴─────┬──────────┐
                    ↓           ↓          ↓
                PostgreSQL    Redis   Dispatcher
                (pgvector)  (limits)    (tasks)
                    ↓           ↓          ↓
                  Memory    Caching    Claude API
                Embeddings   Limits    Canva API
                            Queue    Brave Search

All internal services isolated via Docker network.
Only bot service exposes external port.
